🍔 BurguerVerse

O BurguerVerse é o website de uma hamburgueria artesanal fictícia com temática moderna. Este projeto foi criado para apresentar um cardápio atrativo, a identidade visual da marca e proporcionar uma navegação fluida aos clientes.

🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

HTML5: Estruturação semântica do conteúdo.

CSS3: Estilização com arquitetura organizada e reutilizável.

📁 Estrutura de Arquivos

A organização das pastas e arquivos do repositório é a seguinte:

burguer-verse/
├── CSS/
│   ├── design-system.css
│   ├── global.css
│   └── main.css
├── index.html
└── README.md


📋 Descrição dos Arquivos:

CSS/design-system.css: Contém variáveis de cores, fontes e padrões do sistema de design.

CSS/global.css: Estilos globais, resets e configurações base da aplicação.

CSS/main.css: Estilizações específicas da página principal (index.html).

index.html: Arquivo principal da aplicação contendo a estrutura da página.

README.md: Documentação oficial do projeto.

🚀 Como Executar o Projeto

Clonar o repositório:

git clone https://github.com/seu-usuario/burguer-verse.git


Abrir o projeto:

Navegue até a pasta do projeto.

Abra o arquivo index.html diretamente no seu navegador de preferência ou utilize a extensão Live Server no VS Code.
